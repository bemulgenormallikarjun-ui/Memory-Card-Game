#  Memory Card Game

A simple and interactive Memory Card Game built using **HTML**, **CSS**, and **JavaScript**.

# Features

  16 Memory Cards (8 Pairs)
  Random Card Shuffle
  Click to Flip Cards
  Match Detection
  Move Counter
  Timer
  Restart Game
  Win Message

# Built With

 HTML5
 CSS
 JavaScript

# Project Structure


Memory-Card-Game/

 index.html
 style.css
 game.js
 README.md


# How to Play

 Flip two cards at a time.
 Match all pairs to win.
 Finish in the fewest moves and shortest time.
